# ShopNest – E-Commerce Web Application

A responsive e-commerce web application built with React, allowing users to browse products, explore categories, view product details, and manage their shopping cart.

## Features

- Browse and explore products.
- Filter products by category.
- View individual product details.
- Add and remove products from the shopping cart.
- Increase and decrease product quantities.
- View cart subtotal, tax, and total amount.
- Persistent cart data using localStorage.
- Responsive user interface.
- Loading and error handling for API requests.

## Technologies

- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Context API
- Axios
- Vite

## Installation

Install the project dependencies:

```bash
npm install
```

## Run the Project

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## Application Pages

- Home – Browse featured products.
- Products – Explore and filter products.
- Product Details – View detailed product information.
- Cart – Manage cart items and view the total amount.
- Contact – Get in touch through the contact page.

## Data Storage

Cart information is stored in localStorage to maintain cart items across page refreshes.
